# KineticLiquidMetal pre-built assets

Made before the dash thread by `cargo run --release -p asset-forge -- --lane cloud prebuild kinetic_liquid_metal` (kit in `tools/asset-forge/src/prebuild/kits.rs`). These are layout-independent: the 4K masters are in the Drive folder `FH6 WheelDash v2 - 4K Masters/kinetic_liquid_metal/prebuild/`, and `manifest.json` lists every file. Sprites are also here at 1:1 in `sprites/`, and computed maps (environment, matcaps, look-up tables) at their runtime size in `computed/`. Textures and swatches have no runtime copy yet: the dash's own recipe downsizes the master it picks to the size its Penpot layout needs.

Everything here is computed on the CPU from measured optical constants (Cr: Johnson & Christy 1974; liquid Hg: Inagaki et al. 1981, the measured stand-in for the brief's liquid metal) and the analytic studio, so it is exact, has no seams or noise, and needs no GPU.
