# FaradayMandala pre-built assets

Made before the dash thread by `cargo run --release -p asset-forge -- --lane cloud prebuild faraday_mandala` (kit in `tools/asset-forge/src/prebuild/kits.rs`). These are layout-independent: the 4K masters are in the Drive folder `FH6 WheelDash v2 - 4K Masters/faraday_mandala/prebuild/`, and `manifest.json` lists every file. Sprites are also here at 1:1 in `sprites/`, and computed maps (environment, matcaps, look-up tables) at their runtime size in `computed/`. Textures and swatches have no runtime copy yet: the dash's own recipe downsizes the master it picks to the size its Penpot layout needs.

The brief's metal is galinstan (rho 6440, sigma 0.534); no measured galinstan constants are in the refractiveindex.info database, so liquid mercury (Inagaki et al. 1981), the other room-temperature liquid metal and close in reflectance, stands in. All maps are computed on the CPU, exact and seamless.
