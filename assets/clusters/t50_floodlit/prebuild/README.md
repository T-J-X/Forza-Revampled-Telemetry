# T50Floodlit pre-built assets

Made before the dash thread by `cargo run --release -p asset-forge -- --lane cloud prebuild t50_floodlit` (kit in `tools/asset-forge/src/prebuild/kits.rs`). These are layout-independent: the 4K masters are in the Drive folder `FH6 WheelDash v2 - 4K Masters/t50_floodlit/prebuild/`, and `manifest.json` lists every file. Sprites are also here at 1:1 in `sprites/`. Textures and swatches have no runtime copy yet: the dash's own recipe downsizes the master it picks to the size its Penpot layout needs.

The needle's floodlit shadow is the dash's projection maths; these are the hardware it falls on.
