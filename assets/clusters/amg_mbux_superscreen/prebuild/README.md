# AmgMbuxSuperscreen pre-built assets

Made before the dash thread by `cargo run --release -p asset-forge -- --lane cloud prebuild amg_mbux_superscreen` (kit in `tools/asset-forge/src/prebuild/kits.rs`). These are layout-independent: the 4K masters are in the Drive folder `FH6 WheelDash v2 - 4K Masters/amg_mbux_superscreen/prebuild/`, and `manifest.json` lists every file. Sprites are also here at 1:1 in `sprites/`, and computed maps (environment, matcaps, look-up tables) at their runtime size in `computed/`. Textures and swatches have no runtime copy yet: the dash's own recipe downsizes the master it picks to the size its Penpot layout needs.

Requested by the thread for v5 rain (28 Nov, 09:20). Computed, so clean and exactly seamless; no SDXL.
