# AmgMbuxSupersport pre-built assets

Made before the dash thread by `cargo run --release -p asset-forge -- --lane cloud prebuild amg_mbux_supersport` (kit in `tools/asset-forge/src/prebuild/kits.rs`). These are layout-independent: the 4K masters are in the Drive folder `FH6 WheelDash v2 - 4K Masters/amg_mbux_supersport/prebuild/`, and `manifest.json` lists every file. Sprites are also here at 1:1 in `sprites/`, and computed maps (environment, matcaps, look-up tables) at their runtime size in `computed/`. Textures and swatches have no runtime copy yet: the dash's own recipe downsizes the master it picks to the size its Penpot layout needs.

Requested by the thread (28 Nov, 09:13; TJX: "We want very clean textures and animations"). All computed from periodic noise and exact geometry: no grain, no speckle, no AI artefacts, exact tiles and an exact loop.
