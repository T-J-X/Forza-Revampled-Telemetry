**Category note.** Retro through the LED dot-matrix displays and scoreboards of the 1980s. The dot optics of this brief stay; the phone in its references is a benchmark for the dots, not the subject.

'Micro-LED field': every element is made of round SDF dots (2-stop core 40% toward white, 1 px rim at 35%, a sheen moved by the virtual light). Unlit dots exist only inside glyph cells and bar tracks at inkGhost, never as a full-field grid. Rank 1: 11 outside-in super-dots (30 px), and the gear as an original procedural 5×7 dot glyph on a 30 px pitch (cap 210) at X 1920. Rank 2: speed in three 5×7 cells on a 16 px pitch (cap 112), 280 px right, with ghost 8s as dim dots. Rank 3: a 64×3 dot bar (18 px pitch, 1152 px). Rank 4: a live dyno dot plot under gear and speed at ≤30% luminance. Titillium Web micro-labels.

- **Signature moment:** Self-drawing dyno: at full throttle (≥0.95), each of 64 rpm bins stores the maximum power seen (filled dots) and torque (hollow ring dots), so the car's real wide-open-throttle curve draws itself during the first pulls. A 2×2 hot operating-point cluster rides the curve, and the learned peak-power column gets a 3-dot crown. Once rpm passes it, the tach dots beyond dim to 60% as a live shift hint. Gear changes re-raster the glyph top to bottom in 50 ms (row dots pop 0.6→1.0; the new value is present from frame 1). At the limiter only the super-dot row strobes.
- **Telemetry:** rpm/idle/max + per-car shift → dot bar, super-dots, operating point; power (W) and torque (N·m) at throttle ≥0.95 → dyno bins (fixed [f32; 64] ×2, reset when the car ordinal changes); gear → dot glyph; speed → dot cells; boost → optional shy column; car ordinal / class / PI → dyno reset and a shy class badge; lateral G → dot sheen azimuth and 0/2/4 px parallax.
- **References:** Nothing Phone (3) dot-matrix Glyph Matrix and Ndot typography; stadium micro-LED scoreboards; chassis-dyno power/torque sheets; Oblivion dot-lattice layout (GMUNK)
- **Phase 6 assets:** Procedural only: SDF dots with original 5×7 glyph bitmaps stored as Rust consts (no font licence); shared MSDF Titillium Web 600 for micro-labels.
- **Risk:** Design: v1 failed on rank inversion (rings and a canvas-wide grid dominated, the gear was tiny), and dense dot fields can moiré on the WRGB subpixels. Fix: gear dots ≥24 px and the only bloom; dyno ≤30% luminance with no glow; even-pixel pitches with fwidth AA; no grid outside cells. Perf: about 1,500 instanced dot quads in one draw ≈0.05 ms; dyno storage is fixed arrays, with no per-frame allocation.
